# Shared — Functions (hooks, lib, utils, types)

Logic used across two or more platforms, under the top-level `hooks/`,
`lib/`, `utils/`, and `types/` folders.

## `hooks/`

| File                        | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `useTheme.tsx`              | Light/dark theme state + toggle                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `use-toast.ts`              | Toast notification hook                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `use-mobile.tsx`            | Responsive breakpoint (mobile) detection                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `use-store.ts`              | Generic Zustand-style store selector hook                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `useNativeAuthRefresh.ts`   | Mounts the background refresh for a platform's native session; the actual coordination (single-flight, 13-minute timer, wake-up refresh) lives in `lib/auth/clientRefreshManager.ts`. A failed refresh does **not** redirect — `proxy.ts` handles the real logged-out case on the next navigation                                                                                                                                                                                            |
| `use-sidebar.ts`            | Sidebar open/collapsed state store. `isOpen` is the mobile slide-over; `isRailCollapsed`/`toggleRailCollapsed` is the desktop icon-rail collapse (opt-in per product via `<Sidebar enableRailCollapse>`, now also enabled on Surfboard admin+MDA and both REVA dashboards, not just Surfboard surveyor), defaults to `true` (collapsed) rather than expanded; `isHover`/`setIsHover` drives a collapsed rail temporarily peeking open on hover without touching the persisted collapse state |
| `useConfirm.tsx`            | Promise-based replacement for `window.confirm()`, styled to the design system (readable in dark mode, unlike the native dialog)                                                                                                                                                                                                                                                                                                                                                              |
| `useServerList.ts`          | Generic paginated + searched + filtered list hook — the frontend half of every admin list page (User Management, Notifications, Surf Plans…); pairs with `lib/api/pagination.ts` on the backend and the shared `<Pagination>` component. `fetcher` is deliberately left out of the refetch dependencies                                                                                                                                                                                      |
| `useViewMode.ts`            | Per-page list/grid preference (`ViewMode` from `components/ui/view-toggle`), persisted in `localStorage` under `twonodes-view-mode:<pageKey>`                                                                                                                                                                                                                                                                                                                                                |
| `useSearchParamsUpdater.ts` | Client half of a `searchParams`-driven **server** page: merges updates into the query string and navigates (an empty value deletes its key). Builds from a ref, not the render's `searchParams`, so two quick updates (pick a filter, then type) don't overwrite each other. Also exports `useDebouncedSearchParam` (350 ms debounced `?search=` that resets `page`)                                                                                                                         |

## `components/media/` — the file viewer (ADR-0015)

| `useResolvedUrl.ts`               | Turns a gateway link into the signed URL it redirects to (JSON mode, 15-minute link); other links are used as they are                                                                                                                                                                                               |
| `mediaTypes.ts`                   | `mediaKindFor`, `fileNameOf` (drops the upload prefix), `isGatewayLink`, `downloadHrefFor`, `jsonHrefFor`                                                                                                                                                                                                            |
| `viewerMath.ts`                   | `wrapIndex`, `clampZoom`, `stepZoom`, `pdfPageScale`, `fitPageWidth`, `swipeStep` (a clear sideways swipe steps to the next or previous file; vertical scrolls are ignored)                                                                                                                                          |
| `EnlargeableImage.tsx`            | An inline `<img>` that opens large in the viewer when tapped or clicked; pass `group` to step through the other pictures with the arrows or a swipe. Used for the REVA site photos                                                                                                                                   |
| `__tests__/noNewTabFiles.test.ts` | Fails when a `target="_blank"` or `window.open` appears that is not on the reviewed list (external links only). Add real file links with `MediaLink`                                                                                                                                                                 |

## `lib/auth/` — authentication

See [`docs/auth/technical.md`](../auth/technical.md) for the flows these implement.

| File                           | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `adminInvitations.ts`          | Admin invitations for all three products: `createInvitation` / `resendInvitation` / `revokeInvitation` / `listInvitations`, `getInvitationByToken`, `acceptInvitation` (claim + account creation in one transaction; account born verified `LINK`; audited). 7-day expiry, only the token's sha256 is stored. `INVITABLE_ROLES` bounds what can be granted; `loginPathFor` picks the post-accept login page                                                                                                                                                                                                                                                                                                                                                                                    |
| `authApiClient.ts`             | Client wrapper for native-auth endpoints (login/register/refresh)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `clientRefreshManager.ts`      | Client-side singleton that owns token refresh: single-flight per platform, next background refresh rescheduled to `now + 13m` after any refresh, immediate refresh on tab focus/wake past the window, shared by the 401 interceptors in `surfboard/apiClient.ts`, `reva/apiClient.ts`, `gbc/apiClient.ts`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `cookies.ts`                   | Platform-suffixed auth cookie read/write/clear (`access_token_<platform>`, `refresh_token_<platform>`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `csrf.ts`                      | `validateCSRF(req)` — Origin/Referer validation for mutating routes; an unparseable `Origin` is rejected; a request carrying `Authorization: Bearer` (a native app) passes without Origin or Referer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `emailVerification.ts`         | **Link** verification: `issueAndSendVerificationEmail(platform, user)` — sha256-hashed token in `EmailVerificationToken`, 1-hour expiry                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `emailVerificationOtp.ts`      | **OTP** verification: `issueAndSendVerificationOtp` (6-digit `crypto.randomInt`, sha256-hashed, 10-minute expiry, invalidates prior codes) and `verifyEmailOtp` (max 5 wrong attempts per code, enforced atomically: the attempt is reserved with a conditional update before comparing, the correct code is claimed with a conditional `usedAt` update so only one request consumes it, constant-time digest compare; sets `emailVerified` via `"OTP"`) — atomic cap from PR #260                                                                                                                                                                                                                                                                                                             |
| `emailVerificationSettings.ts` | `getEmailVerificationSettings(platform)` — one normalised read over Surfboard's versioned settings JSON, GBC's per-edition `GBCSettings`, and REVA's `RevaSettings`; returns `{enabled, method, gracePeriodDays, enforcedSince}`, falling back to disabled defaults on any error                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `emailVerificationGate.ts`     | `computeMustVerifyNow(platform, {emailVerified, createdAt})` (new accounts after `enforcedSince` block immediately; older accounts after `enforcedSince + gracePeriodDays`) and `computeVerificationGraceEndsAt` (ISO date for the nag banner, `null` when not in grace)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `jwt.ts`                       | `signAccessToken` (HS256, 15 min), `verifyToken`, `verifyTokenAllowExpired` (only for logout: accepts expiry up to the refresh lifetime but **still verifies the signature** — the old unverified `decodeJwt` helper is gone). `JWTPayload` = `{sub, role, platform, emailVerified, mustVerifyNow}`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `pendingRegistration.ts`       | OTP/link-first registration: `issuePendingRegistration`, `resendPendingRegistration`, `completePendingRegistration`. No user row exists until the emailed secret is confirmed; the email is fixed at issue time, the password binds verification to its chooser, attempts are reserved atomically, claim + account insert share a transaction                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `rateLimit.ts`                 | DB-backed (`LoginAttempt`) 5-per-5-minutes limiter (default; `checkRateLimit` and `consumeRateLimit` accept `{max, windowMs}`). `checkRateLimit` + `recordAttempt` (check, work, record on failure) for login; `consumeRateLimit(identifier, userId?)` records **first** then counts, for anything that costs something or can be guessed in parallel; `getClientIp(req)` prefers `x-vercel-forwarded-for`, then `x-real-ip`, then the first `x-forwarded-for` hop (only the first two are platform-set on Vercel; the last is caller-controlled elsewhere)                                                                                                                                                                                                                                    |
| `session.ts`                   | `getServerSession(platform)` (JWT from an `Authorization: Bearer` header when present, otherwise from the cookie; a bad bearer token never falls back to cookies), `issueMobileSession` / `rotateMobileRefreshToken` (native-app sessions returned in the body, device-tagged, 30-day lifetime; grace-window re-rotation), `MOBILE_REFRESH_LIFETIME_SECONDS`, `getNativeSessionAsLegacyUserData` / **`getEffectiveUserData(platform)`** (native session first, legacy Kinde cookie as fallback — what the admin dashboard layouts use), `issueSession(userId, role, platform, refreshMaxAgeSeconds, userVerification?)` (mints access+refresh, computes the verification claims), `rotateRefreshToken` (reuse detection, expiry inheritance, 30-second concurrency grace), `revokeUserSession` |
| `bearer.ts`                    | `extractBearerToken(headers)` (the token of an `Authorization: Bearer` header, or null) and `getRequestBearerToken()` (reads it from `next/headers`; null outside a request)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `deviceSessions.ts`            | Native-app device sessions: `listDeviceSessions(userId, platform)`, `revokeDeviceSession(userId, platform, familyId)` (scoped to the caller), `revokeFamilyByRefreshToken(platform, raw)` (sign-out)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `userLookup.ts`                | Cross-platform `NativeAuthUser` normalisation: `findUserByEmail` (exact on the unique index, then case-insensitive), `findUserById`, `createNativeUser(platform, data, db?)` (optional `emailVerifiedVia` to be born verified; `db` accepts a transaction client), `updatePasswordHash`, `markEmailVerified(platform, id, via: "OTP" \| "LINK" \| "OAUTH")`, `emailInUse`, `createInvitedUser`                                                                                                                                                                                                                                                                                                                                                                                                 |
