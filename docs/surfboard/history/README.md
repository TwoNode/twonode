# Surfboard — Historical Planning Documents

Everything in this folder pre-dates the 2026-08 architecture rebuild — they're the original planning/progress/requirement documents written while the Certificate of Deposit (CoD) and QR Earnings features were first being built (most dated December 2025). They're kept for historical context, not as current reference: file paths, function names, and "in progress" statuses in these documents describe the codebase as it existed _then_, not today.

**For current documentation of these same features**, see:

- [`../cod-user-flow-summary.md`](../cod-user-flow-summary.md) and [`../cod-user-and-technical-flow.md`](../cod-user-and-technical-flow.md) — the CoD flow as it works today, with current `surfboard/services/*` file paths.
- [`../qr-earnings-stakeholder-brief.md`](../qr-earnings-stakeholder-brief.md) — the QR Earnings brief, with a status note confirming it shipped.
- `docs/development-history/phases/phase-2-surfboard.md` — the actual migration record: what got built, what got renamed, what got deleted.
